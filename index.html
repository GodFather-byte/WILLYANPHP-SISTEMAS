Dúvidas frequentes

As respostas mais comuns, com transparência.

Funciona sem internet?

Sim. O caixa trabalha com os dados guardados no próprio computador, então a venda não para se a internet cair. A internet é usada só para licença, atualizações e avisos.

O sistema emite nota fiscal?

Não. O WillPDV não emite nota fiscal nem integra com maquininha (TEF). A emissão fiscal continua sendo feita pelo meio que a sua casa já usa.

E se o computador estragar? Perco meus dados?

O sistema faz backup com criptografia e permite guardar a cópia em uma pasta externa, para restaurar em outra máquina. Recomendamos testar a recuperação logo na instalação.

Quantos caixas posso usar?

No momento, o sistema é pensado para um caixa por instalação. Se a sua casa precisa de mais de um, fale comigo para avaliarmos.

Posso pedir ajustes para a minha casa?

Sim. O sistema evolui com o uso real das casas, e pedidos de ajuste são bem-vindos.

Qual computador preciso ter?

O WillPDV roda em computador com Windows. Impressora térmica e gaveta são opcionais.
